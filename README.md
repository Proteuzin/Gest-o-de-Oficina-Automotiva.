# Sistema de Gestão de Oficina Automotiva

Sistema web para controle de clientes, veículos e agendamentos de serviços, com autenticação por sessão expirável e proteção de dados (LGPD).

## Como executar o projeto
1. Instale o Python 3 e o Flask:
   `pip install flask werkzeug`
2. Execute a aplicação:
   `python app.py`
3. Acesse no navegador: `http://127.0.0.1:5000`
